# Privacy policy

Docs Short Links does not collect, store or transmit any personal or user data.

The extension runs only on Google Docs document pages
(`https://docs.google.com/document/*`). When you paste, it checks the pasted
text in your browser. If the text is a GitHub issue/PR or Jira issue URL, it
inserts a short link instead. The pasted content is never saved and never
leaves your browser.

The extension makes no network requests, uses no analytics and has no
storage.

Questions: open an issue at https://github.com/pditommaso/gdocs-autolink/issues
